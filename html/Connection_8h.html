Detailed Description

Flow network construction and risk analysis functions.

Builds a Max-Flow network from a problem instance and runs Edmonds-Karp to determine review assignments. Provides risk analysis.

Runs the review assignment algorithm using Max-Flow (Edmonds-Karp).

Parameters
dataThe full problem instance.
excludeReviewerIdID of a reviewer to exclude from the network (-1 = include all).
Returns
A ReviewAssignment containing all assigned paper-reviewer pairs.

Node IDs in the graph:

  • 0: source
  • 1: sink
  • 1000 + submissionId: one node per submission
  • 2000 + reviewerId: one node per reviewer
Parameters
dataThe full problem instance.
excludeReviewerIdReviewer to exclude from the network (-1 = include all).
Returns
A ReviewAssignment containing all assigned paper-reviewer pairs.

Complexity: O(V * E^2) This is the complexity of Edmonds-Karp algorithm. V = number of vertices (2 + |submissions| + |reviewers|) E = number of edges (source->submission + reviewer->sink + submission->reviewer edges).
