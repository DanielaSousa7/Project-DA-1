Writes the assignment result to a CSV file. 

Sorts submissions by paper ID then reviewer ID and reviewers by reviewer ID then paper ID. Also reports any papers that did not receive enough reviews, and runs the risk analysis if requested in the control settings.

Time complexity\+: O(A log A + R \texorpdfstring{$\ast$}{*} A + K), where A is the number of assignments, R is the number of submissions and K is the cost of the risk analysis.
