AssignmentData parseCSV ( string filename)

Parses a conference assignment CSV file into an AssignmentData struct.

The file must contain four sections delimited by lines starting with '#':

  • #Submissions — paper entries
  • #Reviewers — reviewer entries
  • #Parameters — numeric problem parameters
  • #Control — output control settings

Errors (invalid IDs, duplicates) are collected and printed to stderr at the end. Parsing continues even when errors are found.

Parameters
filenamePath to the .csv input file.
Returns
A fully populated AssignmentData struct.
