Runs the review assignment algorithm using Max-\/\+Flow (Edmonds-\/\+Karp). 

Builds a flow network with the following structure:\+
\begin{DoxyItemize}
\item Source → each submission (capacity = Min\+Reviews\+Per\+Submission)
\item \doxylink{struct_submission}{Submission} → reviewer (capacity = 1, only if domains match)
\item \doxylink{struct_reviewer}{Reviewer} → Sink (capacity = Max\+Reviews\+Per\+Reviewer)
\end{DoxyItemize}

Then runs Edmonds-\/\+Karp to find the maximum flow, which corresponds to the maximum number of valid review assignments.

Time complexity:\+ O(V \texorpdfstring{$\ast$}{*} E²)

\item 1:\+ sink
\item 1000 + submission\+Id:\+ one node per submission
\item 2000 + reviewer\+Id:\+ one node per reviewer
