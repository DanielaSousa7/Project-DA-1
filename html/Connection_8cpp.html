◆ riskAnalysis()

vector< int > riskAnalysis ( AssignmentData  data)

Risk Analysis: finds reviewers whose individual absence breaks the assignment. Start by checking if the base assignment is already infeasible, if so return an empty list For each reviewer, removes them from the problem and checks whether a full assignment is still possible. If not, they are considered critical.

Risk Analysis K=1: identifies critical reviewers.

Parameters
dataThe full problem instance.
Returns
Sorted list of critical reviewer IDs.

Complexity: O(R * V * E^2) R = number of reviewers, V = number of vertices, E = number of edges. For each reviewer, we run a full max-flow computation. The final sort is O(R log R).

Runs the review assignment algorithm using Max-Flow (Edmonds-Karp).

Node IDs in the graph:

  • 0: source
  • 1: sink
  • 1000 + submissionId: one node per submission
  • 2000 + reviewerId: one node per reviewer
Parameters
dataThe full problem instance.
excludeReviewerIdReviewer to exclude from the network (-1 = include all).
Returns
A ReviewAssignment containing all assigned paper-reviewer pairs.

Complexity: O(V * E^2) This is the complexity of Edmonds-Karp algorithm. V = number of vertices (2 + |submissions| + |reviewers|) E = number of edges (source->submission + reviewer->sink + submission->reviewer edges).
