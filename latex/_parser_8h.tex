Parses a conference assignment CSV file into an \doxylink{struct_assignment_data}{Assignment\+Data} struct. 

Reads the four sections of the file (\+\#\+Submissions, \+\#\+Reviewers, \doxylink{struct_parameters}{Parameters}, \doxylink{struct_control}{Control}). Reports any errors (duplicate IDs, invalid values) to stderr but continues parsing.

The file must contain four sections delimited by lines starting with \textquotesingle{}\#\textquotesingle{}:\+
\begin{DoxyItemize}
\item {\ttfamily \#Submissions} — paper entries
\item {\ttfamily \#Reviewers} — reviewer entries
\item {\ttfamily \#\doxylink{struct_parameters}{Parameters}} — numeric problem parameters
\item {\ttfamily \#\doxylink{struct_control}{Control}} — output control settings
\end{DoxyItemize}

Errors (invalid IDs, duplicates) are collected and printed to stderr at the end. Parsing continues even when errors are found.
