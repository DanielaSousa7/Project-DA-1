Risk Analysis:\+ finds reviewers whose individual absence breaks the assignment. 

Risk Analysis K=1:\+ identifies critical reviewers.

For each reviewer, removes them from the problem and checks whether a full assignment is still possible. If not, they are considered critical.

Returns an empty list if the base assignment is already infeasible.
