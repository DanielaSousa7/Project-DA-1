void printAssignment ( ReviewAssignment assignment,
AssignmentData data,
string filename )

Writes the review assignment result to a CSV output file.

The output file contains:

  • #SubmissionId,ReviewerId,Match — one line per assignment, sorted by paper ID
  • #ReviewerId,SubmissionId,Match — same assignments, sorted by reviewer ID
  • #Total: N — total number of assignments
  • #SubmissionId,Domain,MissingReviews — papers that did not get enough reviews (if any)
  • #Risk Analysis: 1 followed by critical reviewer IDs (if RiskAnalysis = 1)
Parameters
assignmentThe result of running the assignment algorithm.
dataThe full problem instance (used for missing review checks).
filenamePath to the output CSV file.

Sorts submissions by paper ID then reviewer ID, and reviewers by reviewer ID then paper ID. Also reports any papers that did not receive enough reviews, and runs the risk analysis if requested in the control settings.
