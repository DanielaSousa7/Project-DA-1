Writes the review assignment result to a CSV output file. 

The output file contains:\+
\begin{DoxyItemize}
\item {\ttfamily \#Submission\+Id,Reviewer\+Id,Match} — one line per assignment, sorted by paper ID
\item {\ttfamily \#Reviewer\+Id,Submission\+Id,Match} — same assignments, sorted by reviewer ID
\item {\ttfamily \#Total:\+ N} — total number of assignments
\item {\ttfamily \#Submission\+Id,Domain,Missing\+Reviews} — papers that did not get enough reviews (if any)
\item {\ttfamily \#Risk Analysis:\+ 1} followed by critical reviewer IDs (if Risk\+Analysis = 1)
\end{DoxyItemize}


\begin{DoxyParams}{Parameters}
{\em assignment} & The result of running the assignment algorithm. \\
\hline
{\em data} & The full problem instance (used for missing review checks). \\
\hline
{\em filename} & Path to the output CSV file.\\
\hline
\end{DoxyParams}
Sorts submissions by paper ID then reviewer ID, and reviewers by reviewer ID then paper ID. Also reports any papers that did not receive enough reviews, and runs the risk analysis if requested in the control settings.
